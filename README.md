Friendship Day Website

A heartfelt interactive website created as a Friendship Day gift for someone special.

This project was built to tell a story rather than simply display a webpage. From opening an envelope to reading a personal letter, reliving memories, receiving virtual gifts, and ending with a message of encouragement, every part of the experience is designed to make the recipient feel appreciated and valued.

- Features
  Animated envelope opening
  Interactive friendship letter with page-turning effect
  Background music and sound effects
  Memory gallery
  Golden floating sparkles throughout the experience
  Animated gift reveal
  Cinematic ending sequence
  Final encouragement page
  Bible verses (Jeremiah 29:11 & Joshua 1:9)
  Responsive design for desktop and mobile
  
- Built With
  HTML5
  CSS3
  JavaScript (ES6 Modules)
  Vite
  Three.js
  Canvas Confetti

- Purpose
This project was created as a personal gift for Friendship Day. It combines storytelling, animation, music, and interactive elements to create a memorable experience rather than a traditional website.
Every animation, transition, and visual effect was carefully designed to express gratitude, celebrate friendship, and leave the recipient with a message of hope and encouragement.

- Project Status
  Completed

This project has reached its final version and serves as a finished personal portfolio piece and a memorable Friendship Day gift.
